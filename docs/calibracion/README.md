# Informes de calibración

Un archivo por calibración: `AAAA-MM-DD_<paso>_<tema>.md`, con:

1. **Qué se calibró** y en qué cámara.
2. **Datos:** fecha, condiciones (día/noche, personas), herramienta y comando.
3. **Resultados:** tablas y números.
4. **Decisión:** valores elegidos y por qué.
5. **Cambio aplicado** en `config/camdetector.toml` (copiar la sección).
